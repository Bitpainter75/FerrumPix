  ExifTool is free software under the same terms as Perl itself (Artistic License

5. Optional model files
-----------------------

Model files are NOT part of this package. They are fetched only when the user
presses the button in the settings, and each carries its own license notice
next to the file it belongs to.

  MobileSAM - Apache License 2.0
  MiDaS - MIT License
  LaMa - Apache License 2.0
  SCUNet - Apache License 2.0
  NAFNet - MIT License (with BasicSR, Apache License 2.0)
  Real-ESRGAN - BSD 3-Clause License
  YuNet (OpenCV Model Zoo) - MIT License
  GeoNames place data - Creative Commons Attribution 4.0

  https://github.com/Bitpainter75/FerrumPix-Models

Files that are not in that collection and are fetched from their publisher
instead:

  RAM++ (Recognize Anything Plus), for automatic image keywords
  Apache License 2.0
  https://huggingface.co/anakhiu/ram-plus-onnx-int8
  Three files: the model, its tag list and its threshold list. They are not in
  the collection above because of their size; the model alone is 873 MB.
  Origin, the chain from the original project to this INT8 conversion, and the
  pinned revision are in the licences that travel with the model files.

One file is not in that collection and is fetched from its publisher instead:

  ArcFace ResNet100 - https://huggingface.co/onnxmodelzoo/arcfaceresnet100-8

The ONNX Model Zoo publishes it under the Apache License 2.0 of its own
repository. Its weights, however, come from InsightFace
(https://github.com/deepinsight/insightface), which states that its code is
under the MIT License but that "the models trained with these data are
available for non-commercial research purposes only". Because FerrumPix is
under the GPL-3.0, which assures every recipient the right to use the program
commercially, the file is not passed on with the others. Anyone using it should
read the terms at the source; this notice does not replace them.


6. Map tiles
------------

Map tiles are NOT part of this package. The map view is off by default; once the
user turns it on, it fetches tiles from a tile server, by default
https://tile.openstreetmap.org/, and keeps them in a cache on the device.

  Map data (c) OpenStreetMap contributors
  Open Database License 1.0
  https://www.openstreetmap.org/copyright
  https://opendatacommons.org/licenses/odbl/1-0/

The attribution is shown on the map itself. Tiles are fetched following the
tile usage policy of the OpenStreetMap Foundation:
https://operations.osmfoundation.org/policies/tiles/

6. Optional external programs
-----------------------------

Not part of this package either, and not linked into it: a separate program that
the application starts when the user asks it to.

  dnglab, for converting RAW files to DNG
  Copyright (c) the DNGLab contributors
  GNU Lesser General Public License, version 2.1
  https://github.com/dnglab/dnglab
  It is run as a command line program, so none of its code becomes part of this
  application. No package ships it; it has to be installed separately, and where
  it is missing the conversion says so while everything else works unchanged.
